# 演示脚本（3–5 分钟，7 个节拍）

> 准备：后端 8000、前端 5173 已启动；首次演示前执行过一次示例数据生成。
> 建议每拍截图：首页 / 计划 / 工具卡 / KPI+图表 / 验证 Tab / 报告 / 导出文件。

### 节拍 1 · 定位（20s）

- **操作**：打开 `http://127.0.0.1:5173`。
- **说什么**：“这不是知识库问答。它处理的是结构化数据 + 确定性计算：先给计划，再由受控工具算，最后逐条核对数字。”
- **屏幕上出现**：首页 Hero、问题输入框、右侧上传区、示例数据 chips、最近分析表（若之前跑过）。
- **可被追问**：和 ChatGPT 分析数据的区别？→ 计划可见、工具受控、证据链、数字审计（指向右栏与报告）。

### 节拍 2 · 载入数据 + 提问（30s）

- **操作**：点「销售订单示例数据」→ 输入「为什么 2025 年 9 月销售额相比 6–8 月下降了？」→ 开始分析。
- **说什么**：“7,180 行、14 列的订单明细。示例数据里我故意埋了质量问题：120 行 region 为空、15 个重复订单号、30 行零价、8 行越界日期。”
- **屏幕上出现**：进入工作区，先出现「分析计划」而不是先出结论。
- **可被追问**：数据是真的吗？→ `scripts/generate_sample_data.py`，固定 seed，两次生成 sha256 一致。

### 节拍 3 · 计划先行（30s）

- **操作**：指向计划时间线，展开一步的「计划依据」。
- **说什么**：“每一步都有工具、预期输出、验证方式。计划是结构化 JSON，不是自然语言作文。”
- **屏幕上出现**：5 个步骤，工具 chip（`calculate_metrics` / `create_chart`），当前步自动展开。
- **可被追问**：计划能不能改？→ 当前是“可追问式重跑”（改问题=新 run），不做多轮对话。

### 节拍 4 · 受控工具（40s）

- **操作**：展开任意已完成步骤 → 工具卡「参数 / 结果」两个 Tab → 点 `result_id` 复制。
- **说什么**：“模型只能提供结构化参数；计算在 pandas/DuckDB 里。`result_id` 是证据编号，图表和结论都只能引用它。”
- **屏幕上出现**：参数 JSON（带语法着色）、结果表格（数值右对齐）、耗时为真实毫秒。
- **可被追问**：模型能不能直接写 SQL 干坏事？→ sqlglot AST 白名单 + DuckDB `enable_external_access=false`，39 个攻击用例单测。

### 节拍 5 · 数字与图表（40s）

- **操作**：看 KPI 卡（`¥1970.3 万`、`-18.9%`）→ 图表「查看数据」抽屉。
- **说什么**：“这两个数字和月度趋势来自同一条工具结果；抽屉里就是那 10 行数据，图表没有第二份数据源。”
- **屏幕上出现**：KPI 卡（右下「证据」可展开 result_id）、折线图、抽屉表格。
- **可被追问**：金额单位怎么定的？→ 后端 `format_value`，前端 `formatValue` 同规则（万/亿、百分比 1 位）。

### 节拍 6 · 数字审计（40s）

- **操作**：右栏切到「验证」Tab，展开一条结论的「声称值 → 证据值」。
- **说什么**：“报告写完后，审计器会把每条结论里的数字和证据池逐一比对，0.5% 以内才算 supported；不通过的会被降级进局限性，而不是从报告里消失。”
- **屏幕上出现**：覆盖率环形图（100%）、三条 claim 全部「已证实」、未通过时显示最接近值。
- **可被追问**：阈值为什么是 0.5%？→ 工具输出已 round 到 6 位，0.5% 能容忍显示层四舍五入，又能抓住编造；见 `services/verifier.py`。

### 节拍 7 · 报告与导出（40s）

- **操作**：打开完整报告 → 导出 HTML → 断网后刷新本地文件。
- **说什么**：“报告页是阅读版式；导出的 HTML 是自包含单文件——样式和 SVG 图表都内联，没有任何外链或脚本。”
- **屏幕上出现**：报告（结论+证据编号、核验表、方法论口径、数据质量、局限性）、浏览器下载、离线打开正常。
- **可被追问**：图表导出怎么画的？→ 服务端用同一份 `ChartSpec` 渲染 SVG（`services/charts.py::render_svg`）。
